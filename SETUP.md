# Setup
## A) Profile README
1. Create a PUBLIC repo named exactly `ard12115`.
2. Upload `README.md` and the whole `assets/` folder (keep the structure).
3. Replace YOUR_REAL_EMAIL / YOUR_HANDLE in README.md.
## B) Optional: live interactive page (mouse-orbit Three.js, filters, modal)
1. Create repo `portfolio`, upload `portfolio-repo/index.html` as `index.html`.
2. Settings -> Pages -> Deploy from branch -> main / root.
## Notes
- assets/scene.gif is a frame-by-frame render of YOUR Three.js scene (750 particles, icosahedron, 2 rings, ARD12115 billboard). ~5.7 MB, 300 frames, loops ~12 s.
- tools/scene.py regenerates the GIF; tools/gen.py regenerates the SVG panels.
- Links inside SVG/GIF images aren't clickable on GitHub; use the badges and link row.
